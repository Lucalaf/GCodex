## GCodex 0.1.0 — first RPM release

Cross-platform CNC controller and G-code sender for Grbl 1.1+ machines, with a
live 3D toolpath and stock visualizer. This is the first release of the
`GCodex` repository.

### Install

```bash
sudo dnf install ~/Downloads/Gcodex-0.1.0-1.x86_64.rpm
```

`dnf` resolves relative paths against your current directory — use an absolute
path or `cd` into the download folder first. Verify the download with:

```bash
sha256sum Gcodex-0.1.0-1.x86_64.rpm
# 628a95003757d5c6b954fcb1e1d534a18d235397537a06672da2098e47a02362
```

Installs `/usr/bin/gcodex` plus a desktop entry and hicolor icons. Runtime
dependencies (`gtk3`, `webkit2gtk4.1`, `openssl-libs`, `systemd-libs`) are
declared in the package, so `dnf` resolves them for you.

**Requirements:** Fedora 40+ / RHEL 10+ (x86_64). The binary requires
`GLIBC_2.39`.

### What's in it

- **Grbl 1.1+ streaming** — 127-byte character-counting streamer that keeps the
  planner saturated without overflowing the controller's serial buffer.
- **Virtual controller** — full 60 Hz Grbl simulator for trying the UI without
  hardware.
- **3D toolpath and stock visualization** — wireframe, shaded carve, or hybrid;
  live carving driven by acknowledged line count.
- **Jogging** — step and continuous modes, keyboard shortcuts, and gamepad.
- **Touch-plate Z probing** — parses `[PRB:...]` reports and derives the work
  offset from plate thickness.
- **Self-updater** — checks GitHub at startup and can install a newer RPM in
  place.

### Notes

- The package is **not GPG-signed**. `rpm --checksig` reports `digests OK` and
  `dnf install` only warns that it skipped OpenPGP checks, so no `--nogpgcheck`
  is needed. A host enforcing `gpgcheck=1` would still refuse it.
- Built natively inside a Fedora 41 container so the glibc floor stays at the
  oldest targeted Fedora rather than the build host's.
- This is the first release of the fresh `Lucalaf/GCodex` repository. Earlier
  builds were published under the retired `cnc_send` / `cnc-senda` names; the
  version number restarts at 0.1.0, so an installation of the old 0.1.1 must be
  replaced by hand — the updater never offers a downgrade.
