## GCodex 0.1.1 — worktable grid at bed level

Cross-platform CNC controller and G-code sender for Grbl 1.1+ machines, with a
live 3D toolpath and stock visualizer.

### What's changed

- **The worktable grid now sits at bed level.** It is drawn on the underside of
  the stock instead of the work-origin plane, so it no longer lays a sheet of
  lines across the top of the part. With no job loaded it still sits at the work
  origin.
- **The X/Y axes are depth-tested.** The dashed axis lines were previously
  forced to the front (`depthTest: false`), so they cut straight through the
  stock. The part now occludes them, matching the grid.
- **One source of truth for the stock height.** The shaded stock mesh and the
  grid now derive their Z from the same helper, so they cannot drift apart.

### Install

```bash
sudo dnf install ~/Downloads/Gcodex-0.1.1-1.x86_64.rpm
```

`dnf` resolves relative paths against your current directory — use an absolute
path or `cd` into the download folder first. Verify the download with:

```bash
sha256sum Gcodex-0.1.1-1.x86_64.rpm
# 6f85c79e20ea4dfb78740c9a8f49c2e0616442add472c4c4aaa6005ec3a6976b
```

Installs `/usr/bin/gcodex` plus a desktop entry and hicolor icons. Runtime
dependencies (`gtk3`, `webkit2gtk4.1`, `openssl-libs`, `systemd-libs`) are
declared in the package, so `dnf` resolves them for you.

**Requirements:** Fedora 40+ / RHEL 10+ (x86_64). The binary requires
`GLIBC_2.39`.

### Upgrading from 0.1.0

0.1.0 and later check GitHub at startup and offer newer releases in-app, so this
update should arrive as a prompt — no manual reinstall needed.

### Notes

- The package is **not GPG-signed**. `rpm --checksig` reports `digests OK` and
  `dnf install` only warns that it skipped OpenPGP checks, so no `--nogpgcheck`
  is needed. A host enforcing `gpgcheck=1` would still refuse it.
- Built natively inside a Fedora 41 container so the glibc floor stays at the
  oldest targeted Fedora rather than the build host's.
